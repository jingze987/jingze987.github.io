Learning Structural Consensus Network for Cross-Domain Co-Salient Object Detection

Paper Code

Abstract

Co salient object detection (CoSOD) aims to segment common and salient objects with common semantic attributes in multiple images. Despite significant progress, existing CoSOD methods are typically trained and evaluated under cross dataset setting, without considering distribution shifts between different visual domains. Therefore, their robustness to cross-domain shifts remains limited. To address this challenge, we propose a Structural Consensus Network (SCNet) that utilizes domain-invariant structural representations shared by co-salient objects as prior knowledge to enhance the cross domain generalization ability of CoSOD. SCNet consists of two key components: the Structural Consensus Learning (SCL) module and the Structural Consensus Denoising (SCD) module. The SCL module learns domain invariant structural consensus by extracting structural features and expanding the region level feature statistics while preserving the structure of the object. The SCD module utilizes dynamic convolution kernels as adaptive low-pass filters for local context learning, which can effectively enhance the compactness of consensus while maintaining clear object boundaries. By cascading SCL and SCD, our SCNet is able to effectively extract high-quality structural consensus representations and achieve better performance than multiple state-of-the-art methods on cross domain benchmark datasets.
